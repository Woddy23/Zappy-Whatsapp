Mensagens prontas.
O envio fica consigo.

Na ficha do cliente, clique em WhatsApp ▾ para rever a mensagem e abrir o WhatsApp. O envio é sempre manual.

Como funciona no dia a dia

  1. Abra a ficha do cliente no Zappy e clique no botão verde WhatsApp ▾.
  2. Escolha a mensagem (ex.: “Enviar link da app”, “Como entrar na app” ou “Contactar cliente”).
  3. Reveja ou ajuste o texto no campo de mensagem para aquele cliente específico.
  4. Abra o WhatsApp e envie. Se configurou uma imagem de apoio, copie-a e cole-a no chat (Ctrl+V).

Identificação do Salão

Opções avançadas (link de instalação, mensagens permanentes e imagem PNG)

Link de instalação da app

Opcional. Se preenchido, ativa a opção de mensagem com link de instalação. Se vazio, essa opção fica oculta no menu do cliente para evitar envios incompletos.

Modelos permanentes de mensagem

Variáveis disponíveis: {nome}, {primeiroNome}, {salao} e {linkApp}. Pode personalizar os modelos aqui; o texto de cada envio pode sempre ser ajustado na ficha.

Imagem de apoio PNG (opcional)

Pode guardar um PNG com instruções da app. O botão “Copiar imagem” na ficha permite colá-la manualmente no WhatsApp após enviar o texto. A imagem não é anexada automaticamente.

Dados guardados apenas neste navegador. Sem servidor, chaves de API ou histórico de clientes.
